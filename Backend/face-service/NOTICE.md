- SFace recognition model and its OpenCV Zoo directory: Apache License 2.0.
- YuNet face detector model and its OpenCV Zoo directory: MIT License.
- OpenCV Python wheels: Apache License 2.0.

The model files are downloaded from OpenCV Zoo revision
`47534e27c9851bb1128ccc0102f1145e27f23f98`; the download script verifies
their SHA-256 digests before installing them. Model quality and threshold
performance are not a security certification. This implementation has no
presentation-attack/liveness detection.
